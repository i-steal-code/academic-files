## How to do each block

1. Write each answer on paper without looking. Aim for about 1 minute per mark. If a prompt draws a blank after 30 s, write "?" and move on.
2. Mark it against the key. A point counts if its key idea is there in your own words.
3. For each miss, write the missing point once, word for word, under your answer. That rewrite is what fixes it.
4. Note the misses as prompt number + missing point. Send them to me after the paper if you like; it's optional.
