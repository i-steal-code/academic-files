booklet anchors (name them, look up exact form in paper)

temperature: T/K = T/°C + 273.15


ideal gas: pV = nRT (and pV = NkT)


pressure of ideal gas: p = (1/3)(Nm/V)<c²> or p = (1/3)ρ<c²>


mean translational KE of molecule: (3/2)kT


work done on/by a gas: W = p ΔV (constant p) / area under p-V


first law: ΔU = q + W  (USE THE SIGN CONVENTION PRINTED ON THAT PAPER)


decision tree

1. absolute T in kelvin before any ideal-gas calc


2. count what is fixed: p, V, T, or n


3. isobaric / isochoric / isothermal / adiabatic (if named): which of Q, W, ΔU is zero?


4. ΔU for ideal gas depends only on ΔT (monatomic often use (3/2)nRΔT if asked)


5. work: if p changes, use area on p-V; do not use pΔV blindly


6. efficiency or heat engine: useful output / heat input (from question defs)


quick circumstance -> move

find n or N from p,V,T -> pV = nRT; N = n NA


find rms / <c²> from T -> use mean KE = (3/2)kT and (1/2)m<c²>


heat at constant volume vs constant pressure -> ΔU vs ΔU + W


expansion against constant external p -> W = pΔV; then first law for ΔU or Q


compare two states of same gas -> ratios from pV/T = const if n fixed
