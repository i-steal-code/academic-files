# Paper 1 house model (from converted notes)

This is the standard the rest of the arsenal must obey. Source of truth: Inner Guide, Insight + Qualifier notes, J2 Thinking Routines, Extra Outlines, Updated Essays critique sheet, P1 notes (8881).

## 1. Unpacking (before any case)

**SALT + context** on every title:


| Letter | Means                  | You must generate                                               |
| ------ | ---------------------- | --------------------------------------------------------------- |
| **S**  | Stakeholders / parties | who is helped, hurt, deciding                                   |
| **A**  | Aspects                | cultural, economic, civic, technological, environmental…        |
| **L**  | Levels                 | individual, community, national, global                         |
| **T**  | Time                   | past vs present, short vs long run, “still / no longer / today” |


Also mark the **question angle** (Inner Guide): value-impact, effectiveness, responsibility, possibility, regulation, justification.

**Keyword traps** (must appear in TS, not only intro): *still, only, always, too, nothing more than, more than, should, really, enough, key, inevitable.*

**Question-type moves** (P1 notes):


| Type                                               | What you do                                                                                                                                                       |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **To what extent / how far**                       | Assume the claim has **merit**, then give **limits**. Limits ≠ exceptions.                                                                                        |
| **Absolute** (*always / only / nothing more than*) | Give the merit of the assumption, then **refute the absoluteness**.                                                                                               |
| **Effectiveness / enough**                         | State a **yardstick** first (awareness < behaviour change < sustained change < **alleviation of the problem**). GP has **no “solutions”** — do not list measures. |
| **Comparative** (A vs B, more curse than blessing) | Compare **like with like**. Use **SIT**: scale, impact, time.                                                                                                     |
| **Your society**                                   | Singapore *features* (resource-scarce island that trades, trampoline compact, cohesion, state capacity), not Singapore as a random example dump.                  |


**Do not shift the goalposts.** Every TS must still be answering the actual title (Updated Essays critique Q1).

## 2. Architecture

**Intro (4 jobs):** significance of the debate → dual perspectives → define/scope keywords → **nuanced stand**.

**Body order they mark:**

1. **OV** — fully developed (not a straw man), then **Rebuttal** (attacks the OV’s logic, with ≥1 example).
2. **SV1, SV2** — each with evaluative balance inside (Band 4+).

Mid Band 3 can survive on 1 strong OV + valid rebuttal. Band 4+ needs **balance inside SVs**: exceptions by context, stakeholder, time, or method — not a late “on the other hand” dump. Cambridge’s complaint: balance that is brief, dismissed, or **unfocused**.

**Conclusion (3 jobs):** restate stand → add value → **MOS** (moral of the story): call to action, funded hope, **or** precautionary advice. Not a new argument.

## 3. Paragraph engine (this is Content)

Checklist alignment: **TS → EX (how/why) → 2 examples → insight/CU → link**.

**TS** must carry the title’s keywords (or the EX must immediately carry any leftover context, e.g. “digital age”).

**Two examples, then compare.** Description of each EG: 1–2 lines. Analysis longer than description.

```text
EG1 (who/what/when)
EG2 (who/what/when)
Compare → principle (what both show, or why they diverge)
Qualifier (when/where/for whom it holds)
Implication (policy, ethical, or ranked priority)
Link back to stand
```

**One-line template to memorise:**

> X drives Y **because** Z, **so long as** [condition]; **therefore** [implication].

That template **is** the terminal “so what.” It is named **Insight → Qualifier → Implication**. Recursing past the implication is a new paragraph or a slope.

---



## 4. What “insight / EV / CU” actually are

They overlap. Markers do not want a separate “insight paragraph.” They want these *moves* inside the paragraph:

1. Frame vague words (*progress, enough, ruin, epidemic*).
2. **Mechanism** (pathway, not correlation).
3. **Weigh / prioritise** (which factor is decisive and why).
4. **Conditions and limits** (SALT + time).
5. **Compare** (place, stakeholder, or before/after).
6. **Implication** (not a summary).
7. **Counterfactual / trade-off** (“if X were absent, would the claim still hold?”).

**CU** (syllabus wording to echo, not paste):

- trends, relationships, connections across issues
- adapt ideas across **time and/or place**
- local / regional / global significance; implications for **individual and society**

**EV lenses** (use one, visibly): ideal vs reality · short run vs long run · majority vs minority · theory vs practice · stakeholder split.

**Modals:** one strong modal per claim (*can / should / must / will not*). Do not stack *might perhaps could*.

## 5. Examples: how this house uses them

- **Two per point**, chosen so a **comparison is possible** (same goal, different condition).
- Brief facts; the *principle* is the mark.
- Singapore EG must show a **SG feature**, not a policy name dropped as decoration.
- Weak models in the repo list many names and never extract the principle. Do not copy that habit even when the essay is long.

**Paired-example pattern (gold) — use arsenal cases, not a new country to memorise:**  
Circuit Breaker showed a state that can shut a city; the dormitory outbreak showed whose crowding that growth model had already priced in. Principle: competence and inequality can be the same policy. Compare *conditions* (housing, class), not a second pathogen.

## 6. Word budget + time (90 min)

Updated Essays models run ~1000–1400 words. For 8881, aim **~800–1100**: intro + OV + rebuttal + 2 SVs + conclusion. If time dies, **cut / compress SV2**, not the OV-rebuttal pair (Cambridge: missing balance).
