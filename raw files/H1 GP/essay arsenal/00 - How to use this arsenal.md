# How to use this arsenal

A few deeply understood examples beat many shallow facts. The arsenal has three layers: one file on how to write, one file of sixteen memorised anchors, and seven pillars that hold the depth behind those anchors. Read this file first; every other file is reached from here.

## Workflow

**Before the exam.** Memorise the anchors in `02` pillar by pillar, using the recall order at the top of that file. Read the pillars for the categories you expect to choose; their facts are depth, not a second memorisation load. Write one timed plan a week from a random prelim title, using `01` §7.

**In the exam.**

1. **Select (three minutes).** Cross out the technology and media titles first, then apply the selection rule in `01` §1: a keyword trap, an anchor whose "proves" line answers it, and a counter-example for the rebuttal. The chooser in `02` gives the anchors for each category.
2. **Unpack (two minutes).** SALT, question angle and keyword traps (`01` §2).
3. **Stand.** Write a conditional stand, not a degree (`01` §3).
4. **Write the introduction and OV straight**, then plan R, SV1 and SV2 on the sheet (`01` §7), *therefore* lines first.
5. **Build each SV** from one anchor plus a second example, compared with one move from `01` §5.1, and end with one of the endings in `01` §6.
6. **Range and Singapore check.** Global titles need at least three contexts; "your society" titles stay rooted in Singapore features (`09` §A), with at most one foreign contrast (`01` §5.4–5.6).

---

## Memorisation cap

The memorised load is the sixteen anchors in `02` and the eight Singapore features in `09` §A. Everything else in the pillars is lookup. If a fact is not in an anchor, it should appear in an essay only when it is already secure in your memory.

## Glossary

| Label | Meaning |
|---|---|
| **Anchor** (`02`) | One memorised example or tight pair, with its facts, the mechanism it proves and the condition under which it stops proving it |
| **Hook** (`02`) | The one-line summary of an anchor's mechanism, used as the memory cue for its facts |
| **Argument adaptation** (`01` §5.2) | Dr Chan's method of reusing one argument and example across questions by re-aiming the topic sentence at each question's keyword |
| **Main case and comparison** | The one case a paragraph is built on, and the second case that is allowed only one sentence |
| **OV, R, SV** (`01` §3) | Opposing view; the rebuttal that breaks the OV's absolute word; supporting views that build your own case |
| **Insight, Qualifier, Implication** (`01` §6.3) | The default ending: *X drives Y because Z, so long as [condition]; therefore [implication for the title's keyword]* |
| **SALT** (`01` §2) | Unpacking checklist: stakeholders, aspects, levels, time |
| **SIRDEC** (`09` §F) | Checklist for judging whether a policy works: situation, intent, resources, distribution, effectiveness, coherence |
| **Yardstick** (`01` §2) | The standard a policy is judged against: awareness, behaviour change, sustained change, or alleviation of the problem |
| **Trampoline and net** (`09`, A15) | Singapore's help is designed to restore people's ability to work, learn and own a home (a trampoline); a net supports those who can no longer work |
| **Selection gate** (`08`) | The point where a system sorts people into futures: an exam, a university ranking, or in the US the neighbourhood that decides school funding |
| **Pressure cooker and leaking vessel** (`08`) | East Asian systems that sort so hard the competition harms students, against the US system that demands and funds too little and too unevenly |
| **Involution** (`04` §H) | Competition that grows fiercer while the reward for winning stays the same or shrinks, so every player works harder for no relative gain and none can stop first |
| **Lying flat** (`04` §G, A6) | The stance, named in a 2021 Chinese forum post, of refusing the race for overtime, property, marriage and children while usually still doing a job |
| **The rich control the state, the state controls the rich, the state is rich** (`03` §H) | The US and South Korea; China; Singapore: three ways a government relates to private wealth |
| **Limit case** (`01` §5.6, `03` §J) | An extreme example, such as North Korea under sanctions, that shows the condition under which a general claim stops holding |

## Writing standard

Every line in this arsenal must make sense to a reader who never saw the conversation that produced it: who acted, what they did, who was affected, and why. No coined shorthand, arrow chains or `≠` slogans in place of sentences, no metaphors standing in for an argument, and no table cells that are fragments (full rule: `.cursor/rules/gp-writing-coherence.mdc`). The labels in the glossary are the only shorthand the arsenal keeps.

---

## Keeping the arsenal in order

- New material goes into the pillar it belongs to. It becomes an anchor only if it answers questions in at least three categories and replaces or sharpens an existing anchor; the cap is sixteen unless one is retired.
- Date every volatile figure ("in October 2026"), and recheck the figures in A2, A4 and A5 before the exam.
- Locked GP sittings (`exam papers/LOCKED SITS.md`) are never mined for examples or practice material.
- The stress test in `essay planning/03` records how the anchors perform against a proportional sample of prelim questions; rerun it after any change to the anchors.
