# Planning insights (Q1–Q2 close)

Question-neutral. Carry into Q3 and prelims.

---

## 0. Hybrid planning (how you actually write)

Planning is not “draft the whole essay twice.” It is **prepare the parts that collide**.

| Block | If the chain is already in your head… | Use the planning sheet for… |
|---|---|---|
| **Intro + thesis** | **Pen it immediately** into the essay | Nothing — copying wastes time |
| **OV** | Usually same: write when clear | Only a margin reminder of the OV’s *limit* (what absolute you will kill in R) |
| **R** | Do **not** free-write first | Counter-EG + attack line + stop rule |
| **SV1 / SV2** | Do **not** free-write first | Different nouns · 2 EGs each · I→Q→I · no shared EG with R |

**Purpose of the sheet:** shore up R and SVs so they do not merge, and so each lands on the **same title implication** from a different angle — not to rehearse intro/OV you already own.

**Guardrail:** Spontaneous intro/OV is fine. Spontaneous R/SV is how chaining and missing terminals return. Sheet = R/SV only.

---

## 0b. Time allocation (90 min Paper 1)

| Phase | Min | What happens |
|---|---|---|
| **Select** | **3** | Read all 8; light-unpack 2–3 candidates; pick one |
| **Unpack** | **2** | Deep SALT + angle + keyword trap on the chosen title |
| **Intro** | **~8** | Write straight (hybrid) — thesis already in head |
| **OV** | **~15** | Write straight; margin note only: what absolute R will kill |
| **Plan R + SVs** | **~20** | Sheet only: nouns, EGs, I→Q→I, no collision |
| **Write R** | **~8** | From sheet; half an SV’s length |
| **Write SV1** | **~12** | Full 7-sentence skeleton |
| **Write SV2** | **~12** | Full or compressed if late |
| **Conclusion** | **~5** | Stand + MOS; no new EG |
| **Check** | **~5** | Thin — R/SV leeway eats former ~12 min buffer |

**Totals:** front 5 (select+unpack) · write intro/OV ~23 · mid-plan ~20 · write R→conc ~37 · check ~5 ≈ **90**.

### Branch after unpack

| Flow | Do this |
|---|---|
| **Thoughts flow** | Write intro → OV → **then** 20 min R/SV sheet → write R→conc |
| **Stuck** | Full plan intro→conc on sheet first (will run long). Steal from **check** and **SV2 length**, not from OV or R. Do not restart selection unless the title is clearly wrong. |

### Hard rules

- The **~20 min mid-plan** is protected. Do not “save time” by free-writing R/SV.
- Extra R/SV writing time comes from **check**, not from skipping the sheet.
- If late after plan: compress SV2 (TS + 2 EGs + therefore); never cut R.
- Selection stays at **3 min** — do not deep-unpack all eight.

## 1. Architecture jobs (do not blur)

| Block | Job | Owns | Does not own |
|---|---|---|---|
| **OV** | Best case for the claim | Merit of the title’s assumption | Your full theory |
| **R** | Kill the **absolute** | 1 counter-EG + logic punch | Second EG; full SV theory |
| **SV1** | First **positive** layer | New noun + 2 EGs + I→Q→I | Repeating R |
| **SV2** | Second **non-overlapping** layer | Different noun + 2 EGs + I→Q→I | Same EG as R or SV1 |
| **Conclusion** | Stand + value + MOS | Synthesis | New argument |

**R = wrecking ball. SVs = construction.**

**Chain test:** If SV1 could open with “Furthermore…” after R, rewrite. Different **nouns** in R-stop / SV1 / SV2.

---

## 2. I→Q→I (the terminal)

Not a longer “so what?” loop. **Convert this paragraph’s effect into a verdict on the title.**

| Move | Prompt | Lands when |
|---|---|---|
| **Insight** | *because* — principle from the EGs | Mechanism, not summary |
| **Qualifier** | *so long as / for whom / when* | Claim is limited, not absolute |
| **Implication** | *therefore* + **title keyword** | Answers the question |

**Wrong:** keep asking “so what?” about effects.  
**Right:** answer *why this paragraph matters for the title* — then stop.

If the last line could fit any essay on the topic (“X matters / X is essential”), it has not answered **this** title yet.

**On the plan:** force three lines under every body block before leaving it:

```text
I: because ___
Q: so long as / for whom ___
Imp: therefore [title keyword]
```

Blank = unplanned.

## 3. Promise big → deliver big

| Planning sin | Fix |
|---|---|
| Stand/R without counter-EG | Write **EG first**, derive the claim from it |
| SV as concept only | No concept bullet without **2 named EGs** |
| Thin SV / missing terminal | Write **therefore** on the plan before prose |
| R as long as an SV | Cap R at **half** one SV |
| Policy shopping (“gov should…”) | Argue what **already exists / already happens** |

---

## 4. How to invent two SVs without overlap

1. Split the title’s noun into **layers** (e.g. input vs architecture; speech vs memory).  
2. Or split **stakeholders / timescales**.  
3. Ask: *what would be impossible if the OV were total?* → that silence → SV.  
4. Second silence → SV2.

**Exam SV package (~160–190 words, 7 sentences):**  
TS → EG1 → EG2 → compare → because → so long as → therefore.

**Ratio:** 2 lines fact, 5 lines analysis.

---

## 5. Bottom-line Band 4 floor

Need all of: valid intro + real OV + R with EG + ≥1 full SV (2 EGs + qualifier + terminal) + second angle (SV2 or conclusion limit).

If time dies: **never cut R**; compress SV2; keep OV–R pair.

Missing SV2 = ceiling problem, not automatic fail. Missing R or straw OV = worse.

---

## 6. Value / arts terminals (general rule)

Land on a **named human good**, not a prediction.

| Good | Stop at |
|---|---|
| **Human experience** | Life thinned to work + consumption; emotion/expression dulled |
| **Shared public world** | Something in common besides the job |
| **Memory** | Society not only an economic machine |
| **Civic speech** | Disagreement has a language — not “gov reforms” |
| **Recognition** | See someone beyond a role — not “prejudice ends” |

**Fake terminals:** GDP salvation, soft power as foreign policy, civilisation collapse.

**Luxury titles:** OV = how society **ranks** under strain; SV = what the **good** still is. Ranking ≠ the whole truth of “nothing more than.”

---

## 7. Pre-flight (30 sec, every plan)

1. R has a **named counter-EG**?  
2. SV1 / SV2 **different nouns**?  
3. Each SV: **2 EGs + therefore**?  
4. No EG shared between R and an SV?  
5. R **shorter** than one SV on the page?  
6. Every body block has **I / Q / Imp** written?

All yes → write.
