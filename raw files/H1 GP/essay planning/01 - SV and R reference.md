# SV and R reference (planning sheet ↔ essay)

Use before every plan. Question-neutral.

**Hybrid rule:** Intro/thesis (and usually OV) go straight onto the script when the logic is already clear. **This sheet is for R and SVs** — prevent collision/merge; align terminals to the title. Do not double-write intro/OV here.

---

## R — rebuttal

### Job
Kill the **absolute / total / only** in the OV. Not build your full case.

**R = wrecking ball. SVs = construction.**

### On the planning sheet (5 bullets max)

```text
R slot: "The OV overstates because ___"
Counter-EG: [one named anchor that breaks the OV's logic]
Attack line: OV explains [X], not [all of X]
Stop rule: do NOT use merit / institutions / delivery as full SV arguments here
```

**Counter-EG test:** If this example were absent, would the OV still look totally true? If yes, it belongs in R. If it builds your positive theory, it belongs in SV1.

### In the essay (~80–100 words, 3–4 sentences)

```text
1. Concede OV's partial truth (one clause)
2. Name what the absolute word wrongly assumes
3. Counter-EG (one line: who/what/when)
4. Logic punch: therefore the total claim fails
```

**Illegal in R:** second example, full mechanism essay, policy list, "furthermore democracy also…"

### Promise-big / deliver-big fix

| Planning sin | Essay symptom | Fix |
|---|---|---|
| R stand says "absolute kills OV" | Paragraph repeats thesis | Write the **counter-EG first** on the plan, then derive the stand from it |
| No counter-EG listed | R reads as opinion | One bullet: *name + event + what it proves against OV* |
| R as long as SV | Time dies; SVs starve | Cap R at half an SV's word count |

## SV — supporting view

### Job
Build **one new layer** of your case. Each SV owns a **different noun**.

### On the planning sheet (8 bullets)

```text
SV# noun: [one word — delivery / institutions / identity / etc.]
TS slot: "Democracy / X still ___ because ___"
EG1: [who/what/when — one line]
EG2: [who/what/when — one line]
Compare: both show / diverge because ___
Because: [mechanism — one pathway]
Qualifier: so long as / for whom / when
Terminal: therefore [title keyword]
```

**Chain test:** Read R's last line and SV1's TS. If SV1 could start with "Furthermore…" and mean the same thing, rewrite — you chained.

### In the essay (~160–190 words, 7 sentences)

```text
1. TS — new noun + title keyword
2. EG1 — one line
3. EG2 — one line
4. Compare — one sentence (principle from the pair)
5. Because — mechanism
6. So long as — qualifier
7. Therefore — lands on title keyword
```

**Ratio rule:** 2 lines of fact, 5 lines of analysis. Thin SV = too much scene-setting.

### Promise-big / deliver-big fix

| Planning sin | Essay symptom | Fix |
|---|---|---|
| Concept only ("political merit → effectiveness") | Paragraph stalls at abstraction | No concept bullet without 2 named EGs beneath it |
| One EG | No compare possible | Second EG must share a frame with EG1 |
| Ends at "effects amplified by…" | No terminal | Write **therefore** line in plan before writing prose |
| SV2 = what state should do | Policy essay | Reframe as what **already exists / already happens** |
| Same EG as R | Overlap, feels thin | EG exclusivity: R's counter-EG cannot reappear in any SV |

## 30-second pre-flight (every plan)

1. R has a **named counter-EG**? (not just a stand)
2. SV1 and SV2 have **different nouns**?
3. Each SV has **2 EGs + therefore**?
4. No EG appears in both R and an SV?
5. R is **half the length** of one SV on the page?

All five yes → safe to write.

---

## If time dies in the exam

| Block | Minimum |
|---|---|
| R | 3 sentences + 1 counter-EG |
| SV1 | Full 7-sentence skeleton |
| SV2 | TS + 2 EGs in one line + therefore |
| Conclusion | Stand + one limit (only if SV2 was cut) |

Never expand R to fill space. Never write SV2 before SV1 is complete.
