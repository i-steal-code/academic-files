## Post-mortem (31 Aug, same day)

**Actual clock:** EG map first → write thesis+OV in one go → pause at R → finish. Not the rehearsed hybrid (intro/OV first, then 20 min R/SV sheet).

**Question choice:** Sound. Absolute (*always*) + obligation (*should*) + not *your society* (US + SG legal). Arsenal fit: `06` openness/trampoline + US 2024 kitchen-table/immigration.

**What landed:** SALT; *always* flagged; OV (US/ICE, jobs) vs SV2 (asylum/right to live) are different nouns; SG ageing/TFR as labour arithmetic is the right feature.

**Loose ends (architecture):**
- R (SG talent = boon) does not wreck OV (US jobs). Different country + different migrant type = extra SV, labelled R.
- SV1 (SG workers) then chains that same SG-economy noun.
- Legal R: OV’s zero-sum / native-harm does not entail *always* refuse — **or** US kitchen-table anger is real but does not generalise to every country’s design.
- *Welcome* ≠ *admit for labour*. SV1 is arithmetic need. If the essay never named that gap, *should welcome* was under-answered.
- *Always* needed a qualifier on the page: tiered inflows, capacity, not “swamped” (`06` Wong 2024). Sheet has none.
- Asylum EG as “2000s Middle East” is dated; 2024 displacement would have been tighter. Fine if the principle (duty to protect life) carried.

**Carry to P2 AQ (same jobs, smaller):** OV real; R = one counter to the passage’s absolute; SV = new noun; last line of each para answers the AQ prompt, not “Singapore has schemes.”
