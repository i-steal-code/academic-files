How to use it

  • Topical: work through each chapter's Core list in order. It covers every question type the A-Level keeps asking, most important first. Stretch is for when Core is done.
  • Papers: sit each set (P1 and P2) timed, in order. Stop anywhere from Floor to Cap, but always finish with the two Final rehearsal sets.
  • The topical lists use no question from these ten sets or from RI Prelim 2026, so the papers stay unseen.
  • Skip notes mark parts outside the 2026 syllabus. Printed solution notes flag mistakes in the official answers.
